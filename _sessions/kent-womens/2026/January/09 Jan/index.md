# Warmup
Starting with a 3 vs 3 half court game, within the 3m line and volleying on the attack
  - Later move onto an attack without a jump
  - We can then move back into the full length of the court using defense and a jumping attack (can work on 2 / 3 step approaches)

Looking to possibly add in some queen of the court 3 vs 3 - again more game time to get used to playing again

# Double take drill 
Not taking credit, this comes from here; https://www.theartofcoachingvolleyball.com/out-of-system-double-take-drill/
(members only video)

We are going to play 6 vs 6, everyone is going to rotate everywhere, the player to take the first pass has to take the 2nd and set the ball for an attack, can use anywhere to attack
- Fed ball in by someone / coach

# Setter at 1
- Playing a regular game without set positions and rotations, anyone who is at position 1 is the setter
- if the setter takes the first ball, we want the player at position 5 to take the 2nd
