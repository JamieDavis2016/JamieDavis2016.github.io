# Warmup (20mins)
- Touch and go, playing the game within the 3m line, everytime you touch the ball, run to the endline and back, initiation of ball is a float serve at 3m line working on contact
- Target serving, looking at serving to 1 or 5 on court

# Ameoda serving
The credit goes to John Forman for this drill.

(1st server to get it in) Servers sit and you have to get everyone else to sit by catching the ball
We replace the first server with the 2nd only once, to make it so that the first server gets more chances to serve

Race between two teams

# Serving into transition
- playing on 2 Half courts, the server serves, defender passes to setter, for the set. Then setter sets for the defender to attack

# Service game
- 2 / 3 in receive
- Ball in from coach if the serve is out
  - An attack gets a point
  - Passer becomes setter, setter becomes server
- To 15 points


# Game
Extra rules, 2 points for a deep hit
